# Artifact Output Conventions

> **Single source of truth for where Coferlandia skills save generated artifacts.**
> Every skill that writes files MUST follow this convention unless it explicitly declares
> an exception. When in doubt, check this file first.

---

## Default output root

All artifacts generated by Coferlandia skills go under **`.coferlandia/`** at the
target project's root, plus whatever sub-path the skill itself declares.

```
.coferlandia/{skill-declared-subpath}/artifact.ext
```

## Standard repo artifacts (exception)

The following files are considered **standard repo artifacts** and stay at the
project root even without an explicit exception declaration:

| File | Reason |
|------|--------|
| `README.md` | Universal project entry point |
| `AGENTS.md` | Agent onboarding file expected at repo root |
| `LICENSE` | Legal file, always at root |
| `RUNBOOK.md` | Operational file expected at repo root |

A skill may declare **additional** standard-repo overrides in its own `SKILL.md`,
but it MUST do so explicitly with an `## Output Exceptions` subsection. If it
doesn't declare an override, the default is `.coferlandia/`.

## How a skill declares its output path

1. In the skill's `SKILL.md`, add an `## Output Location` section.
2. State the base path as `.coferlandia/{sub-path}/`.
3. If any artifact goes to a standard repo file, list it in an
   `## Output Exceptions` subsection with the full path at project root.

Example:

    ## Output Location

    All artifacts go to `.coferlandia/documentation/`.

    ### Output Exceptions

    - `README.md` — standard repo artifact (replaces/updates project root)
    - `AGENTS.md` — standard repo artifact (replaces/updates project root)

## Read paths are unchanged

This convention applies only to **write output**. Discovery and read paths
(e.g., `docs/inbox/`, `docs/`, `notes/`, `documentation/`, `design/`, etc.)
remain exactly as each skill defines them.

## Rule ownership

This file owns the artifact output convention. Skills reference it; they don't
duplicate it. If a skill's `SKILL.md` contradicts this file, this file wins.
