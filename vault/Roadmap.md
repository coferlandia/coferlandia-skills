# Roadmap — coferlandia-skills

---

## Fase 1 — Meta-infraestructura ✅ (Genesis, 2026-06-11)

La fundación del repo. Skills que permiten crear más skills.

- [x] `meta/skill-factory` — Crear nuevas skills (active)
- [x] `meta/build-agentic-repo` — Diseñar/auditar repos agénticos autoritativos (active, skill ejemplar)
- [ ] `meta/skill-auditor` — Revisar y mejorar skills (draft → active)

> Estado real de skills: ver [`skills/INDEX.md`](../skills/INDEX.md) (fuente de verdad única).

**Criterio de éxito:** Un agente puede llegar al repo y crear una skill nueva correctamente, sin instrucciones del humano.

## Fase 2 — Engineering Core

Skills de ingeniería de software para el stack de Coferlandia.

- [ ] `engineering/code-review` — Review con estándares de Coferlandia
- [ ] `engineering/deploy-checklist` — Pre-deploy verification
- [ ] `engineering/debug` — Debugging estructurado
- [ ] `engineering/architecture-decision` — ADRs en formato Coferlandia

**Criterio de éxito:** Un agente puede hacer code review de un PR y generar un checklist de deploy sin que el humano especifique los criterios.
