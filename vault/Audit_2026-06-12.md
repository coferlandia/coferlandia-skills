# Auditoría inicial - 2026-06-12

## Alcance

Revisión de los 13 skills iniciales, protocolo, índice, vault y scripts. La referencia externa
canónica usada fue [agentskills.io/specification](https://agentskills.io/specification).

## Hallazgos corregidos

### Alta

- `when_to_use` estaba documentado como campo oficial y aparecía en 11 skills, pero no pertenece
  al frontmatter canónico. Sus disparadores se migraron a `description`.
- El validador anterior aprobaba 13/13 sin detectar campos no canónicos, drift del índice, links
  rotos, contratos de scripts ni evidencia conductual.

### Media

- `README.md` enlazaba un `Genesis_Plan.md` inexistente en la raíz.
- El índice describía la suite de logging como cinco roles aunque contiene ocho.
- La documentación de compatibilidad de clientes era histórica y no distinguía rutas reales.
- Las skills activas tenían texto libre en `metadata.tested`, pero no casos positivos/negativos
  versionados para conservar su intención de triggering.

### Baja

- Un `.pyc` estaba versionado dentro de una skill.
- Varias reglas locales repetían partes del estándar en vez de enlazarlo como autoridad.
- El `rg` del entorno reporta un patrón inválido en un `.gitignore` ancestro fuera de este repo;
  es un riesgo operacional externo, no un defecto de estas skills.

## Resultado

Se agregó `coferlandia-skill-testing`, casos conductuales por skill y un runner JSON que comprueba
frontmatter, metadata local, índice, links, scripts y secretos. Los smoke tests reales de clientes
siguen siendo necesarios porque ningún test estático garantiza el comportamiento de selección de
un modelo concreto.

## Riesgos residuales

- El análisis de secretos es heurístico y no reemplaza un secret scanner dedicado.
- Los casos conductuales registran intención, pero no califican automáticamente respuestas de LLM.
- La selección de skills puede variar entre modelos y versiones; discovery correcto no sustituye
  pruebas periódicas de triggering positivo y negativo.

## Instalación local

- Se instalaron 14 junctions en `~/.agents/skills` para Codex, Gemini CLI y Copilot CLI.
- Se instalaron 14 junctions en `~/.claude/skills` para Claude Code.
- Las 28 rutas resuelven al repositorio canónico y exponen su `SKILL.md`.
- Una prueba temporal fuera del repo confirmó propagación inmediata de cambios por junction.
- Copilot CLI quedó instalado mediante `gh copilot` en versión 1.0.61.
